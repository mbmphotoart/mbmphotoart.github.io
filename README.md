# MBM Photo Art

Portfolio fotografico responsive in HTML, CSS e JavaScript, pronto per GitHub Pages.

## Pubblicazione consigliata: https://mbmphotoart.github.io/

Per ottenere questo indirizzo, il repository deve chiamarsi esattamente `mbmphotoart.github.io`.

1. Accedi a https://github.com/new
2. Crea un repository chiamato `mbmphotoart.github.io`.
3. Imposta il repository come **Public** e, se vuoi, aggiungi un README.
4. Apri il repository e scegli **Add file → Upload files**.
5. Estrai questo archivio ZIP sul computer e carica `index.html`, `README.md` e `.nojekyll` nella cartella principale del repository (non caricare la cartella contenitore).
6. Premi **Commit changes**.
7. Vai in **Settings → Pages**.
8. In **Build and deployment**, seleziona **Deploy from a branch**.
9. Seleziona branch `main` e cartella `/(root)`, quindi premi **Save**.
10. Attendi la pubblicazione e visita https://mbmphotoart.github.io/. La prima pubblicazione può richiedere alcuni minuti.

Guida ufficiale: https://docs.github.com/en/pages/quickstart

## Personalizzazione

- Sostituisci le immagini dimostrative con le tue fotografie.
- Per aggiungere le foto al repository, crea una cartella `images/` e aggiorna i rispettivi `src` in `index.html`.
- La sezione contatti è volutamente senza indirizzo email: quando sarai pronta, inserisci il tuo indirizzo e aggiorna il pulsante nella sezione `contact`.
- Il sito è statico e non richiede framework o server. I font e le immagini di esempio provengono da servizi esterni e richiedono una connessione Internet.
